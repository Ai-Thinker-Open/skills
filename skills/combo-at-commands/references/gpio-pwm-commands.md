# 控制指令 — GPIO与PWM

## 3 IO

查询或设置 映射表

## 3.1 AT+SYSIOMAP — IO映射表

### 查询: AT+SYSIOMAP?

| 项目 | 内容 |
|------|------|
| 描述 | 查询IO管脚映射关系表 |
| 响应 | `+SYSIOMAP:PinNumber:<PinNumber>,PinMap:<pin1>,<pin2>,...,<pinN>` |
| 说明 | PinNumber：表示当前映射表一共有几组数据 |
| 示例 | `AT+SYSIOMAP?` → `+SYSIOMAP:PinNumber:6,PinMap:NC,5,20,NC,15,NC` → OK |

### 设置: AT+SYSIOMAP=<PinNumber>,<pin1>,<pin2>,...,<pinN>

| 参数 | 类型 | 必选 | 取值范围 | 说明 |
|------|------|:---:|----------|------|
| PinNumber | 整数 | 是 | — | 要设置的IO总数 |
| pinxx | 整数/NC | 是 | 1~254 或 NC | 模组IO引脚（从模组左上角逆时针排序，引脚序号从1开始）对应的芯片引脚编号。如果模组没有对应芯片引脚则设置为NC |

| 响应 | OK |
|------|------|
| 示例 | `AT+SYSIOMAP=4,3,5,NC,1` → OK |
| 示例说明 | 共设置4个IO映射：模组1号引脚→芯片3号引脚；模组2号引脚→芯片5号引脚；模组3号引脚→NC（不可用）；模组4号引脚→芯片1号引脚 |
| HELP描述 | QueryandsetIOmap |

> 各型号的IOMap映射表参考 附件1 各个型号模组IOMap表

配置 功能

## 3.4 AT+PWMCFG — PWM配置（寄存器单位）

### 设置: AT+PWMCFG=<pin>,<cycle>,<duty>

| 参数 | 类型 | 必选 | 取值范围 | 说明 |
|------|------|:---:|----------|------|
| pin | 整数 | 是 | — | 模块上的引脚（从模组左上角开始逆时针排序，从1开始） |
| cycle | 整数 | 是 | — | PWM周期（寄存器单位） |
| duty | 整数 | 是 | — | 占空比时间（寄存器单位） |

| 响应 | OK |
|------|------|
| HELP描述 | SetPWMconfig |
| 注意 | Ai-WB2系列模组一共有5路PWM，同时开启时必须注意芯片引脚的IO序号对5取余不能重复，否则只会有一个生效，例如设置了IO1/2/6实际只有IO2/6生效，IO1被IO6覆盖了 |
| 备注 | 该指令设置的单位是芯片的周期寄存器，相同参数在不同的模组上的效果可能不同，如果在精度可以满足要求的情况下推荐使用AT+PWMCFGS设置，这个指令相同参数在不同模组上的效果会基本保持一致（不同芯片可能会存在几us的差异） |
