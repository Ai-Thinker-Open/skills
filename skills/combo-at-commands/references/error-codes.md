# Combo模组AT指令错误码参考

## 系统框架错误码 (0-63)

| 错误码 | 含义 | 排查方法 |
|--------|------|----------|
| 0 | 成功 | 指令执行正常 |
| 1 | 不支持该指令 | 当前平台未移植该功能，检查模组型号是否支持 |
| 2 | 指令参数包含不支持的操作 | 检查当前平台对该指令的支持范围 |
| 3 | 指令格式错误 | 参数数量错误，检查指令格式 |
| 4 | 参数错误 | 参数内容错误，检查取值范围和格式 |
| 5 | 参数长度错误 | 指令长度超过最大支持长度 |
| 31 | 指令未结束 | 异步上报状态中，用于状态机判断，不返回消息 |
| 32 | 未知错误 | 未处理的错误类型 |
| 33 | malloc错误 | 内存不足，减少同时运行的任务或减小buf大小 |
| 34 | 读取buf失败 | 缓冲区读取异常 |
| 35 | 写buf失败 | 缓冲区写入异常 |
| 36 | 配置错误 | 内存中加载的配置错误，检查OTA端口等配置参数 |
| 37 | 创建任务失败 | 系统资源不足，重启模组后重试 |
| 38 | Flash读写失败 | Flash存储异常，可能需要重新烧录 |
| 39 | 串口波特率不支持 | 检查设置的波特率是否在支持列表中 |
| 40 | 串口数据位不支持 | 检查数据位设置(5/6/7/8) |
| 41 | 串口停止位不支持 | 检查停止位设置(1/1.5/2) |
| 42 | 串口校验位不支持 | 检查校验位设置(None/Odd/Even) |
| 43 | 串口流控不支持 | 检查流控设置 |
| 44 | 串口配置失败 | 串口配置写入失败，重启后重试 |
| 45 | 用户名/密码错误 | WiFi密码或MQTT用户名密码错误 |
| 46 | 低功耗模式错误 | 不支持的低功耗模式，检查mode参数 |
| 47 | 未初始化配置数据 | 包含IO映射数据未初始化，先执行AT+SYSIOMAP |
| 63 | 通用错误 | 没有携带其它信息的通用错误 |

## WiFi错误码 (64-95)

| 错误码 | 含义 | 排查方法 |
|--------|------|----------|
| 64 | WiFi未初始化或初始化失败 | 先执行AT+WMODE设置WiFi模式 |
| 65 | WiFi模式错误 | 单AP模式无法连接WiFi，需设置为STA或AP+STA模式 |
| 66 | WiFi连接失败 | 检查SSID和密码是否正确，AP是否在范围内 |
| 67 | WiFi连接成功但获取IP失败 | DHCP服务器无响应，尝试设置静态IP |
| 68 | 获取加密方法失败 | AP的加密方式不被支持 |
| 69 | 没有扫描到指定AP | 检查SSID是否正确，AP是否开启，信号是否足够 |
| 70 | WiFi扫描启动失败 | WiFi模块异常，重启后重试 |
| 71 | WiFi扫描超时 | 信号环境复杂或模块异常 |
| 72 | 开启AP热点失败 | 检查AP参数配置，信道是否合法 |
| 73 | 获取路由器/AP信息失败 | WiFi连接异常，重新连接 |
| 74 | 网卡未运行 | STA或AP网卡未启动，先设置WiFi模式 |
| 75 | WiFi国家码错误 | 检查AT+WCOUNTRY设置的国家码 |
| 76 | 当前配网模式错误 | 检查AT+WCONFIG的配网模式参数 |
| 95 | WiFi连接未知错误 | 重启模组后重试 |

## Socket错误码 (96-127)

| 错误码 | 含义 | 排查方法 |
|--------|------|----------|
| 96 | 创建socket失败 | 系统资源不足，删除不用的连接后重试 |
| 97 | socket连接失败 | 检查服务器IP/域名和端口是否正确 |
| 98 | DNS失败 | 域名解析失败，检查域名或设置DNS服务器(AT+WDNS) |
| 99 | socket状态错误 | TCP还未连接就尝试收发数据，先确认连接状态 |
| 100 | socket类型错误 | 操作不适用于当前socket类型 |
| 101 | socket发送失败 | 网络异常或连接已断开 |
| 102 | socket接收失败 | 无数据可读或连接异常 |
| 103 | socket监控线程创建失败 | 系统资源不足 |
| 104 | socket bind出错 | 端口被占用，更换端口 |
| 105 | 无法进入透传 | socket类型不对或数量不满足条件 |
| 106 | PING测试全部丢包 | 网络不通，检查WiFi连接和目标地址 |
| 107 | PING测试部分丢包 | 网络不稳定，检查信号强度 |
| 108 | SSLConfig错误 | SSL配置参数有误 |
| 109 | SSL校验错误 | 加密类型不支持或证书错误，检查证书配置 |
| 127 | socket未知错误 | 重启模组后重试 |

| 错误码 | 含义 | 排查方法 |
|--------|------|----------|
| 128 | GPIO模式错误 | 配置了输入却执行输出指令，先确认引脚模式 |
| 129 | IO未烧录映射表 | 操作的引脚号超出IO映射表范围，先执行AT+SYSIOMAP |
| 130 | NC引脚无法控制 | 该引脚为串口/VCC/GND等，不可用AT指令控制 |
| 131 | 引脚模式设置错误 | 不支持的GPIO模式 |
| 132 | GPIO上下拉设置错误 | 不支持的上下拉模式 |
| 133 | 不支持的PWM周期 | 硬件不支持该PWM周期值 |
| 159 | GPIO操作未知错误 | 重启模组后重试 |

## HTTP(S)错误码 (160-191)

| 错误码 | 含义 | 排查方法 |
|--------|------|----------|
| 160 | HTTP响应头格式错误 | 服务器返回了非标准HTTP响应 |
| 191 | HTTP请求未知错误 | 检查URL、端口、网络连接 |

## MQTT错误码 (192-224)

| 错误码 | 含义 | 排查方法 |
|--------|------|----------|
| 192 | MQTT连接方式错误 | 检查scheme参数(1=TCP, 2=SSL) |
| 193 | MQTT连接失败 | 检查服务器地址、端口、client_id、用户名密码 |
| 194 | MQTT配置错误 | 检查MQTT参数是否完整设置 |
| 195 | 发布MQTT消息失败 | MQTT未连接或topic格式错误 |
| 196 | MQTT订阅列表已满 | 最多5条订阅，先取消不用的订阅 |
| 197 | MQTT没有收到响应 | 服务器无响应，检查网络和服务器状态 |
| 198 | MQTT忙或连接超时 | 等待当前操作完成或重启MQTT |
| 199 | MQTT取消订阅失败 | topic未订阅或已断开 |
| 224 | MQTT未知错误 | 断开重连后重试 |

## 快速排查指南

### WiFi连接失败
1. 检查错误码 → 66(连接失败)/67(获取IP失败)/69(未找到AP)
2. 执行`AT+STAINFO?`查看当前状态
3. 确认SSID和密码正确
4. 确认WiFi模式为STA(1)或AP+STA(3)
5. 检查信号强度`AT+WRSSI`

### MQTT连接失败
1. 检查错误码 → 192(方式错误)/193(连接失败)/194(配置错误)
2. 执行`AT+MQTT?`查看当前配置
3. 确认WiFi已连接且获取到IP
4. 确认服务器地址、端口、client_id、用户名密码正确
5. 如使用SSL，检查证书配置

### Socket连接失败
1. 检查错误码 → 96(创建失败)/97(连接失败)/98(DNS失败)
2. 执行`AT+SOCKET?`查看连接状态
3. 确认WiFi已连接
4. 检查服务器地址和端口
5. 如使用域名，先用`AT+WDOMAIN`测试DNS解析

### 蓝牙操作失败
1. 检查错误码 → 228(状态不允许)/233(扫描失败)/235(连接失败)
2. 确认蓝牙模式正确(从机=0/主机=1)
3. 名称/UUID等参数需在蓝牙关闭状态下设置
4. 瑞昱系列需先开AP再开蓝牙
