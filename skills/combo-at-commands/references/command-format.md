# 指令格式和默认配置说明

## 1.1 串口默认配置

如果没有特殊说明，AT指令串口和下载串口使用同一个串口，配置为 **115200,8N1**

## 1.2 启动信息

模组上电后打印以下启动信息：

```
################################################
arch:<芯片型号>,<芯片版本流水号>
company:Ai-Thinker|B&T
ble_mac:<蓝牙MAC>          // eg：94c960123456(小写字母)，如果没有本行不打印
wifi_mac:<WIFISTAMAC>       // eg：94c960123456(小写字母)，如果没有本行不打印
sdk_version:<SDK版本号>     // 芯片原厂SDK的版本号
firmware_version:<固件版本号> // 格式"release/v1.0.0"
compile_time:<编译时间：月/日/年/时/分/秒>
ready
################################################
```

**备注：**
1. 换行使用`\r\n`
2. 客户建议检测`ready`来检测启动信息，不建议检测固件版本号和编译时间
3. 启动信息中的固件版本号是模组固件版本号，不是combo指令版本号。combo框架版本号需通过`AT+GMR`查看。

**版本号格式：** `v主版本号.次版本号.迭代号`
- 主版本号改变：不兼容的修改（删除指令或修改现有指令）
- 次版本号改变：添加新接口（新AT指令或向下兼容的修改）
- 迭代号改变：bug修复（不涉及接口修改）

## 1.3 指令格式

```
CMD[opt][param1,param2,...]\r\n
```

| 元素 | 说明 | 示例 |
|------|------|------|
| CMD | 指令名称（不区分大小写） | AT |
| opt=NA | 不带参数，直接执行 | AT |
| opt=? | 查询状态 | AT? |
| opt==param1,param2,... | 带参指令，多个参数逗号分隔 | AT=1 |

**参数规则：**
- 参数中包含逗号需要用双引号引起来
- 参数中不能出现`\n`
- 第一个和最后一个参数为空时必须使用双引号括起来
- 指令以`\r\n`结尾（实际检测`\n`，前面的`\r`会被忽略）

## 1.4 指令响应格式

### 1.4.1 执行成功
```
\r\nOK\r\n
```
中间不能有任何其他消息。

### 1.4.2 执行错误
```
\r\n+<CMD>:<error_code>\r\nERROR\r\n
```
`error_code`为错误码（部分平台支持），AT串口不能打印其它错误信息。

### 1.4.3 查询成功
```
\r\n查询结果\r\nOK\r\n
```

### 1.4.4 未知指令
```
Unknowncmd:<串口输入的所有内容，包含参数>
```

**示例：**
```
输入: ATAA\r\n
返回: Unknowncmd:ATAA

输入: ATAA=123\r\n
返回: Unknowncmd:ATAA=123
```
