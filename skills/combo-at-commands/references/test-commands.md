# 产测指令

## 6.1 标准指令

### 6.1.1 ##boot — 开发板按键触发信号（URC）

| 项目 | 内容 |
|------|------|
| 描述 | 当使能开发板测试后，如果按键触发就会在串口打印此数据 |
| 格式 | `\r\n##boot\r\n` |

### 6.1.2 AT+NodeMCUTEST — 开发板测试使能

#### 设置: AT+NodeMCUTEST=<start>

| 参数 | 说明 |
|------|------|
| start | 0=关闭，1=开启 |

| 响应 | OK |

### 6.1.3 AT+LEDTEST — LED测试指令

#### 格式1: AT+LEDTEST=<start>[,<ledLev>,<ledNum>,<ledPin1>,…,<ledPinN>]

| 参数 | 说明 |
|------|------|
| start | 0=关闭跑马灯，1=开始跑马灯（红、绿、蓝、黄、白切换，每个亮1000ms） |
| ledLev | LED有效电平（部分模组支持）：0=低电平点亮，1=高电平点亮 |
| ledNum | LED数量（部分模组支持） |
| ledPinX | LED对应的GPIO序号，多个引脚用逗号分开（部分模组支持） |

#### 格式2: AT+LEDTEST=<start>[,<modulename>]

| 参数 | 说明 |
|------|------|
| start | 0=关闭跑马灯，1=开始跑马灯 |
| modulename | 配置支持的模组型号（与系统命名相同）。已支持：BW20-12F |
