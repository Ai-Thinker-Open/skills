# 产测指令

## 6.1 标准指令

### 6.1.1 ##boot — 开发板按键触发信号（URC）

| 项目 | 内容 |
|------|------|
| 描述 | 当使能开发板测试后，如果按键触发就会在串口打印这个数据 |
| 格式 | `\r\n##boot\r\n` |

### 6.1.2 AT+NodeMCUTEST — 开发板测试使能

#### 设置: AT+NodeMCUTEST=<start>

| 参数 | 类型 | 必选 | 取值范围 | 说明 |
|------|------|:---:|----------|------|
| start | 整数 | 是 | 0：关闭，1：开启 | 开发板测试功能开关 |

**响应：** OK

---

### 6.1.3 AT+LEDTEST — LED测试指令

#### 格式1: AT+LEDTEST=<start>[,<ledLev>,<ledNum>,<ledPin1>,…,<ledPinN>]

| 参数 | 类型 | 必选 | 取值范围 | 说明 |
|------|------|:---:|----------|------|
| start | 整数 | 是 | 0：关闭跑马灯，1：开始跑马灯（红、绿、蓝、黄、白切换，每个亮1000ms） | 跑马灯开关 |
| ledLev | 整数 | 否 | 0：低电平点亮，1：高电平点亮 | LED有效电平（部分模组支持） |
| ledNum | 整数 | 否 | — | 一共有多少个LED（部分模组支持） |
| ledPinX | 整数 | 否 | — | LED对应的GPIO序号，多个引脚用逗号分开（部分模组支持） |

**响应：** OK

#### 格式2: AT+LEDTEST=<start>[,<modulename>]

| 参数 | 类型 | 必选 | 取值范围 | 说明 |
|------|------|:---:|----------|------|
| start | 整数 | 是 | 0：关闭跑马灯，1：开始跑马灯（红、绿、蓝、黄、白切换，每个亮1000ms） | 跑马灯开关 |
| modulename | 字符串 | 否 | BW20-12F | 配置支持的模组型号，该型号与系统中的命名相同（部分模组支持） |

**响应：** OK
