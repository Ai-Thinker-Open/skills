# 一、Rd-01 系列（24GHz · 三合一）

**频段**: 24GHz | **功能**: Wi-Fi + BLE + Radar 三合一 | **应用**: 人体存在检测

### 特点
- 集成 Wi-Fi、BLE、雷达三合一
- 人体存在检测
- 适用于智能家居、照明控制
- 一款模组同时解决通信 + 人体感知

---

# 二、Rd-03 系列（24GHz · 人体检测）

**频段**: 24GHz | **应用**: 人体存在 / 运动 / 微动检测（此系列型号最丰富，按功能与功耗细分）

### 型号列表

| 型号 | 功能定位 | 特点 |
|------|----------|------|
| Rd-03_V2 | 人体检测 | 静止、运动或微动的人体检测 |
| Rd-03_V1 | 人体检测 | 运动、微动人检测（旧款） |
| Rd-03D_V2 | 多目标轨迹 | 【更低功耗】多目标轨迹识别与跟踪、轨迹检测 |
| Rd-03D_V1 | 多目标轨迹 | 多目标轨迹识别与跟踪（旧款） |
| Rd-03L_V2 | 低功耗 | 【超低功耗】运动、微动和静止人体的精确感知 |
| Rd-03L_V1 | 低功耗 | 【低功耗】运动、微动和静止人体精确感知（旧款） |
| Rd-03E | 测距 / 手势 | 测距与手势识别 |
| Rd-03H | 极窄封装 | 35.0×7.0mm，人体存在检测 |

> 推荐优先选择 **V2 版本**（功耗更低、更省电），V1 为旧款。

---

# 三、Rd-04 系列（10GHz · 微动检测）

**频段**: 10GHz | **应用**: 微动检测

### 特点
- 可集成光敏元件
- 微动检测
- 适用于照明、安防（如灯控、检测微弱动作）

---

# 四、Rd-6X 系列（60GHz · 高精度）

**频段**: 60GHz | **型号**: Rd-60 / Rd-61 | **应用**: 高精度、精准测距、手势识别

### 特点
- 雷达频谱 58~64GHz，连续扫频带宽 6GHz
- 天线 1T3R（支持 1T1R / 1T2R / 1T3R 配置）
- EIRP 17.5dBm，FOV 水平/垂直 120°
- 最远感应 8m，最近 0.01m
- 超小尺寸 22.5×18.5mm
- UART Shell 控制指令 + FFT 雷达检测数据输出
- 物理层支持 BLE5 / 802.15.4，协议层 BLE 5.3（Rd-6X 兼具无线）

### 型号
- **Rd-60**: 高精度 / 精准测距版
- **Rd-61**: 高精度版

---

# 五、Rd-100 系列（24GHz · 感应）

**频段**: 24GHz | **应用**: 人体存在 / 微动感应 | **芯片**: 矽典微 ICL111A

### 型号列表

| 型号 | 尺寸(mm) | 封装 | 特点 |
|------|----------|------|------|
| Rd-101A | 12.0×12.0 | DIP-5 | 运动人体最远感应 6m |
| Rd-103A | 23.0×6.0 | DIP-5 | 运动人体最远感应 6m |

> 通过 UART Shell 控制指令配置。

---

# 六、Rd-Kit 调试板

- 搭配 APP 进行数据检测与调参
- 支持雷达模组调试

| 微动检测 | Rd-04 | 10GHz 微动 |
| 精准测距/手势/高精度 | Rd-60 / Rd-61 | 60GHz |
| 多目标轨迹跟踪 | Rd-03D_V2 | 轨迹检测 |
| 极窄结构 | Rd-03H | 35×7mm |
| 低功耗人体感知 | Rd-03L_V2 | 超低功耗 |
| 小尺寸 24G 感应 | Rd-101A / Rd-103A | 矽典微 6m |
