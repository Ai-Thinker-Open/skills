# 雷达模组选型参考

数据来源: https://github.com/Ai-Thinker-Open/Ai-Thinker-Docs

## Rd-01 系列 (24GHz)

**频段**: 24GHz | **功能**: Wi-Fi + BLE + Radar | **应用**: 人体存在检测

### 特点
- 集成 Wi-Fi、BLE、雷达三合一
- 人体存在检测
- 适用于智能家居、照明控制

---

## Rd-03 系列 (24GHz)

**频段**: 24GHz | **应用**: 人体存在/运动检测

### 型号列表

| 型号 | 特点 |
|------|------|
| Rd-03 | 基础款 24GHz 雷达 |
| Rd-03E | 增强版 |
| Rd-03D | 数字输出版 |
| Rd-03L | 低功耗版 |
| Rd-03_V2 | V2版本 |

---

## Rd-04 系列 (10GHz)

**频段**: 10GHz | **应用**: 微动检测

### 特点
- 可集成光敏元件
- 微动检测
- 适用于照明、安防

---

## Rd-6X 系列 (60GHz)

**频段**: 60GHz | **应用**: 精准人体检测

### 特点
- UART Shell 控制指令
- FFT 雷达检测数据输出
- 高精度检测

---

## Rd-Kit 调试板

- 搭配APP进行数据检测与调参
- 支持所有雷达模组调试

---

## 雷达选型指南

| 频段 | 型号 | 适用场景 |
|------|------|----------|
| 10GHz | Rd-04 | 微动检测、照明控制 |
| 24GHz | Rd-01 | 人体存在检测、智能家居 |
| 24GHz | Rd-03系列 | 人体检测、运动感应 |
| 60GHz | Rd-6X | 精准检测、呼吸监测 |

### 选型建议

| 需求 | 推荐型号 |
|------|----------|
| 人体存在检测 | Rd-01 / Rd-03 |
| 微动检测 | Rd-04 |
| 高精度检测 | Rd-6X |
| 需要WiFi/BLE | Rd-01 |
| 低功耗应用 | Rd-03L |
