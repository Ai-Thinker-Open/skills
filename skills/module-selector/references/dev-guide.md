## WiFi 模组开发评估

### Ai-WB2 系列

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐ | AT指令快速上手，二次开发需学习BL602 SDK |
| 文档完善度 | ⭐⭐⭐⭐ | 中英文规格书齐全，社区教程丰富 |
| SDK 成熟度 | ⭐⭐⭐ | 基于博流 SDK，持续更新 |
| 社区活跃度 | ⭐⭐⭐⭐ | 论坛活跃，问题响应快 |
| 供货稳定性 | ⭐⭐⭐⭐⭐ | 成熟产品，长期供货 |

**开发资源:**
- SDK: https://github.com/Ai-Thinker-Open/Ai-Thinker-WB2
- 开发环境: Linux/Windows 均支持
- 烧录工具: BL602 Flash Download Tool

**常见问题:**
- Q: 如何进入烧录模式？ A: 拉低 IO8 后上电
- Q: AT固件和开发固件区别？ A: AT固件支持AT指令，开发固件用于二次开发
- Q: 支持哪些开发环境？ A: Eclipse + GCC，VSCode + PlatformIO

**典型应用:**
- 智能插座/开关
- 温湿度传感器
- 智能照明
- 门锁/门铃

### Ai-M61 系列

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐⭐ | 需要学习 BL618 SDK，支持音视频 |
| 文档完善度 | ⭐⭐⭐⭐ | 规格书齐全，SDK文档完善 |
| SDK 成熟度 | ⭐⭐⭐⭐ | bouffalo_sdk 持续维护 |
| 社区活跃度 | ⭐⭐⭐ | 较新产品，社区逐步增长 |
| 供货稳定性 | ⭐⭐⭐⭐ | 新品，供货稳定 |

**开发资源:**
- SDK: https://github.com/bouffalolab/bouffalo_sdk
- 支持 Camera、MJPEG、Display、Audio Codec
- 支持 USB2.0、以太网(EMAC)

**常见问题:**
- Q: 支持哪些屏幕接口？ A: QSPI、DBI、RGB
- Q: 最大分辨率？ A: 取决于 PSRAM 大小，支持 VGA
- Q: 音频编解码？ A: 内置 Audio Codec

**典型应用:**
- 智能门铃
- 视频监控
- 音频设备
- 带屏智能家居

---

### Ai-M62 系列

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐⭐ | 与 M61 类似，无音视频功能更简单 |
| 文档完善度 | ⭐⭐⭐⭐ | 规格书齐全 |
| SDK 成熟度 | ⭐⭐⭐⭐ | 与 M61 共用 SDK |
| 社区活跃度 | ⭐⭐⭐ | 逐步增长 |
| 供货稳定性 | ⭐⭐⭐⭐ | 多种封装可选 |

**开发资源:**
- SDK: https://github.com/bouffalolab/bouffalo_sdk
- 支持低功耗模式 (120μA)

**常见问题:**
- Q: 与 M61 区别？ A: M62 无 Camera/Display 接口，功耗更低
- Q: 如何实现低功耗？ A: 使用 TWT (Target Wake Time) 机制
- Q: CBS封装用途？ A: 用于 SDIO/USB 转接

**典型应用:**
- 低功耗传感器
- 电池供电设备
- 智能家居控制

### Ai-M64 系列

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐⭐ | 需关注低功耗配置 |
| 文档完善度 | ⭐⭐⭐⭐ | 规格书、FAQ 齐全 |
| SDK 成熟度 | ⭐⭐⭐⭐ | bouffalo_sdk 支持 |
| 社区活跃度 | ⭐⭐ | 新品，社区较小 |
| 供货稳定性 | ⭐⭐⭐ | 新品，逐步上量 |

**开发资源:**
- SDK: https://github.com/bouffalolab/bouffalo_sdk
- FAQ: [点击查看](https://aithinker-static.oss-cn-shenzhen.aliyuncs.com/docs/media/WiFi/M64/M64P/FAQ/Ai-M64P-32S%E6%A8%A1%E7%BB%84FAQ%E6%8C%87%E5%AF%BC%E6%96%87%E6%A1%A3.pdf)

**常见问题:**
- Q: 保活功耗多少？ A: 低至 90μA
- Q: 支持哪些低功耗模式？ A: PDS掉电睡眠、HBN休眠
- Q: 与 M62 区别？ A: M64 使用 BL616CL 芯片，功耗更低

**典型应用:**
- 电池供电 IoT 设备
- 新能源设备监控
- 低功耗传感器节点

## BW 系列 (双频 WiFi)

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐⭐ | 需要了解双频 WiFi 配置 |
| 文档完善度 | ⭐⭐⭐ | 文档较少 |
| SDK 成熟度 | ⭐⭐⭐ | 瑞昱 SDK |
| 社区活跃度 | ⭐⭐ | 用户较少 |
| 供货稳定性 | ⭐⭐⭐⭐ | 稳定供货 |

**常见问题:**
- Q: 为何选择双频？ A: 避免 2.4GHz 拥堵，5GHz 更稳定
- Q: BW20 vs BW16？ A: BW20 性能更强，支持 Mesh/CSI

**典型应用:**
- 高清视频传输
- 需要稳定连接的设备
- Mesh 组网

## LoRa 模组开发评估

### Ra-01 系列

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐ | SPI 接口，AT指令可选 |
| 文档完善度 | ⭐⭐⭐ | 基础文档齐全 |
| SDK 成熟度 | ⭐⭐⭐ | 常用 LoRa 库支持 |
| 社区活跃度 | ⭐⭐⭐⭐ | LoRa 用户群体大 |
| 供货稳定性 | ⭐⭐⭐⭐⭐ | 成熟产品 |

**常见问题:**
- Q: 最远通信距离？ A: 空旷环境 5-8km
- Q: 需要外部 MCU 吗？ A: 是的，通过 SPI 控制
- Q: 支持 LoRaWAN 吗？ A: Ra-01 不支持，需用 Ra-08/Ra-09

**典型应用:**
- 农业传感器
- 智能抄表
- 远距离监控

## 雷达模组开发评估

### Rd-01 系列

| 评估维度 | 评分 | 说明 |
|----------|------|------|
| 开发难度 | ⭐⭐ | 串口输出，配置简单 |
| 文档完善度 | ⭐⭐⭐ | 基础文档齐全 |
| SDK 成熟度 | ⭐⭐⭐ | 专用配置工具 |

**常见问题:**
- Q: 检测距离多远？ A: 5-8米（可调）
- Q: 能区分人和物吗？ A: 可以，通过参数配置
- Q: 与 PIR 区别？ A: 雷达可检测静止人体，PIR 只能检测运动

**典型应用:**
- 人体存在检测
- 智能照明
- 安防报警

## 选型决策树

```
用户需求
├── 需要 WiFi？
│   ├── 是 → 需要音视频？
│   │   ├── 是 → Ai-M61
│   │   └── 否 → 需要低功耗？
│   │       ├── 是 → Ai-M64 > Ai-M62
│   │       └── 否 → 高性价比？→ Ai-WB2
│   └── 否 → 需要双频？
│       ├── 是 → BW系列
│       └── 否 → 需要 LoRa？
│           ├── 是 → 点对点？→ Ra-01
│           │   └── 组网？→ Ra-08/Ra-09
│           └── 否 → 需要雷达？
│               ├── 是 → Rd-01/Rd-03
│               └── 否 → 需要定位？→ UWB
```
