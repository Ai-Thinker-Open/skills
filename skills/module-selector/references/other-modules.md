# 一、UWB 超宽带定位

**定位精度**: 10cm | **应用**: 室内高精度定位、资产追踪、智能仓储

| 型号 | 芯片 | 定位方式 | 特点 |
|------|------|----------|------|
| BU01 | DW1000 | TWR 双向测距 | 集成天线、RF、电源，速率 6.8Mbps |
| BU03 | DW3000 | TDOA / PDOA | 集成板载陶瓷天线 + RF |
| BU04 | DW3000 + STM32F103 | TDOA / PDOA | 双天线、双板载/IPEX 外接，内置 MCU |

> 从 2024 起主推 DW3000 方案（BU03/BU04），支持 AT 指令 + TWR/PDOA 上位机算法。

# 三、蓝牙 BLE

## 1. PB 系列（奉加微 PHY62xx 方案）

**应用**: 智能灯、智能插座、智能家电 | 支持 Android/iOS APP 和微信小程序控制

| 型号 | 芯片 | 协议 | 特点 |
|------|------|------|------|
| PB-03 | PHY6252 | BLE 5.4 | 通用 BLE 模组 |
| PB-03F | PHY6252 | BLE 5.4 | 带 Flash / 天线可引板 |
| PB-03M | PHY6252 | BLE 5.4 | 小尺寸 |
| PB-04 | PHY6222 | BLE 5.4 | 新一代升级 |

## 2. TB 系列（泰凌微 TLSR8250 方案）

**应用**: 智能灯/插座/空调 | 符合 BLE 5.0 及 SIG Mesh 规范，可对接天猫精灵

| 型号 | 芯片 | 协议 | 特点 |
|------|------|------|------|
| TB-02 | TLSR8250 | BLE 5.0 + SIG Mesh | 经典款 |
| TB-03F | TLSR8250 | BLE 5.0 + SIG Mesh | 小尺寸 |
| TB-04 | TLSR8250 | BLE 5.0 + SIG Mesh | 升级款 |
| TB-05 | TLSR8250 | BLE 5.0 + SIG Mesh | 新款 |

> PB（奉加微）与 TB（泰凌微）是**两个不同芯片平台**，开发工具链不同；TB 更偏 SIG Mesh 组网与天猫精灵生态。

# 四、NB-IoT 低功耗广域网

**应用**: 智能表计、低功耗广域网 | 芯片: EC616S（3GPP Rel14）

| 型号 | 特点 |
|------|------|
| EC-01 | 基础款 NB-IoT |
| EC-01G | NB-IoT（带 GNSS 定位版） |
| EC-01F | NB-IoT（带 GNSS 定位版，可搭配 GP-01） |

> EC-01G / EC-01F 常与 GP 系列组合实现"定位 + NB 回传"。

# 六、AI 语音识别

**应用**: 离线语音识别 | 芯片: 云知声 US516P6（锋鸟 M）

| 型号 | 特点 |
|------|------|
| VC-01 | AI 离线语音识别模组 |
| VC-02 | AI 离线语音识别模组（升级款） |

> 特征：中英双语、单 MIC、AEC 回声消除、150 条本地指令、识别率 98%+、识别 <100ms。
