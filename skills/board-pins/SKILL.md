# Ai-Thinker 开发板引脚配置

为 Ai-Thinker 各款开发板提供准确、可查询的引脚/管脚配置。**每个开发板的引脚数据以单板一个的文件存放在 `references/<board>.md`**，按板名索引，便于后续逐板扩充规格书。

## 使用方式

1. **确定开发板型号**：从用户描述中确认板名（如 `Ai-WB2-12F-Kit`）。若缺失，先追问型号，不要臆造。
2. **查板卡索引**：先读 `references/kit-boards-index.md`，确认该板是否已知、是否已拆解引脚、以及官方规格书链接。
3. **加载对应参考文档**：板名 → 归一化文件名（板名小写、空格/连字符保留、其余非法字符替换为 `-`），到 `references/` 下取对应 `.md`。
   - `Ai-WB2-12F-Kit` → `references/ai-wb2-12f-kit.md`
   - 若该板已在索引但**未拆解引脚**（`references/<board>.md` 不存在），先据索引的规格书链接核对，并明确告知"暂无引脚数据，可提供官方规格书/原理图以补充"。
   - **注意**：除 `ai-wb2-12f-kit.md` 为人工核对外，其余板的 `references/<board>.md` 由规格书**自动解析生成**，引脚号/名称较准、但功能说明可能存在断词，**使用前建议与官方规格书/原理图核对**（尤其涉及接线/复用冲突时）。
4. **按需查询**：
   - **引脚 → 功能**：在参考文档的「引脚定义表」「功能索引」中定位。
   - **功能 → 引脚**：先在「功能索引」里按 SPI / IIC / ADC / PWM / UART / GPIO 找可用引脚。
   - **电源/串口/指示灯**：查「电源引脚」「默认串口」「指示灯 / 按键」小节。
4. **回落（未收录/未拆解板）**：若板名不在 `references/kit-boards-index.md` 中，明确告知「当前未收录该板」，并请用户提供官方规格书或原理图以补充。

## 查询注意（避坑规则）

- **默认 NC / 不可用**：标 `NC` 或「默认 NC，不可使用」的引脚不能当普通 IO。
- **与内部 Flash 共用**：标「与模组内部 Flash 共用，不推荐使用」（如 IO1 / IO2）的引脚勿用于外设，避免破坏固件。
- **功能复用冲突**：很多引脚一针多功能（SPI_SCLK / IIC_SDA / PWM / ADC 共用）。**同一引脚的多个功能同时使用会失效**，务必检查复用关系后再接线。
- **特殊引脚默认语义**：EN（芯片使能）、RST（复位）、TX/RX（默认串口）注意其默认功能与高低电平有效方向。
- **供电与电平**：注意 3V3 / 5V 供电及 I/O 电平上限（VDDIO），避免外设电平不匹配。
- **烧录流程**：如有烧录/复位按键，告知用户烧录时的按键配合顺序。

## 输出规范

- 给出该板的**电源引脚**（3V3 / 5V / GND）、**可复用 IO**、**默认串口（TX/RX）**、**指示灯与按键对应引脚**。
- **高亮「不可用 / 不推荐」引脚与冲突点**，优先提醒用户踩坑风险。
- 不确定时，回到 `references/<board>.md` 核对源规格书版本，**不臆造引脚**；需要精确到官方原理图时，建议用户查阅该板官方文档。

## references 扩充规范（给维护者）

- 每板一个文件：`references/<board>.md`，文件名 = 板名小写 + 连字符。
- 文件必须包含：板卡概要、引脚定义表、电源引脚、功能索引（按外设）、指示灯/按键、避坑提示、数据来源与核对说明。
- 数据来源注明官方规格书**版本号**；更新板卡资料时保持同一板一文件，避免数据漂移。
