## 使用与避坑提示（重要）

- **默认 NC / 不可用**：脚 3、8（IO22）、9（IO0）、20（IO21）、21（IO20）、22、23（NC）、27（IO8）默认不可用，勿当作普通 IO。
- **与内部 Flash 共用**：脚 30（IO1）、28（IO2）与模组内部 Flash 共用，**不推荐使用**，避免破坏固件；如需使用请联系安信可。
- **功能复用冲突**：大量引脚一针多功能（SPI / IIC / PWM / ADC 共用）。**同一引脚不能同时用作冲突的多个功能**，规划时务必核对上表。
- **RGB 灯脚与 IIC / SPI / PWM / ADC 复用冲突**：RGB 灯占用 IO14（红）、IO17（绿）、IO3（蓝）。这三个脚同时挂有多种功能——
  - IO14：SPI_SS / IIC_SCL / PWM_CH4 / ADC_CH2
  - IO17：SPI_MOSI\MISO / IIC_SDA / PWM_CH2
  - IO3：SPI_SCLK / IIC_SDA / PWM_CH3
  **若点亮 RGB 灯（这三脚作为数字输出），就不能同时把这些脚用作对应的 IIC/SPI/PWM/ADC 功能**，否则总线、PWM 或灯都会失效。尤其注意 IO14=SCL、IO17 与 IO3=SDA，**用它做 IIC 时务必避开 RGB 灯脚**。
- **EN / RST**：EN（脚12）默认高有效使能，**与 RST 不能同时使用**；RST（脚13）默认悬空、低有效复位，定制需联系安信可。
- **供电与电平**：I/O 电平上限受 VDDIO 约束（见规格书电气特性表），3V3/5V 供电需匹配外设电平。
- **烧录流程**：先按烧录按键，同时短按复位按键，再上电/识别串口（默认 115200 bps）。
